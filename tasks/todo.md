# 备餐单「加料」按成品聚合（套餐展开）— 2026-08-18

## 老板原话
> +料的项目看到很乱，尤其是荷包蛋用3颗蛋，只是显示独立+的荷包蛋，下饭王套里面
> 有荷包蛋，可是只是显示所需的蛋，把他们规划成所需的东西，不用分拆那么细。

## 问题
备餐单**按来源拆**，同一样东西劈成好几段；套餐里的成品（荷包蛋/炒蛋/加饭）被压成
原料形态（「鸡蛋(生) 8颗」），看不出要做什么。「🥚 鸡蛋合计」只数纯蛋 label，
19 个含蛋加料 + 3 道含蛋主菜全部算 0。

**改前**（2026-08-19 晚餐真实单）
```
加料  西兰花 200g（蒜蓉西兰花炒蛋）· 西兰花 400g（家乡下饭王套）
    · 鸡蛋(生) 3颗（蒜蓉西兰花炒蛋）· 鸡蛋(生) 8颗（家乡下饭王套）· 鸡蛋(生) 3颗（荷包蛋）
🥚 鸡蛋合计  荷包蛋 共 3 颗          ← 实际要 14 颗
```
**改后**
```
加料  蒜蓉西兰花炒蛋 ×3（西兰花 600g · 鸡蛋 9颗）· 荷包蛋 ×5（鸡蛋 5颗）· 加饭 ×2
🥚 鸡蛋合计 共 14 颗：荷包蛋 5 颗 · 蒜蓉西兰花炒蛋 3 份 9 颗
```
